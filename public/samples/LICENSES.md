# Créditos e licenças das amostras de bateria

## `tr808/` — Roland TR-808

Gravações de um Roland TR-808 feitas por **Michael Fischer (Technopolis)**, 09/08/1994,
16 bits / 44,1 kHz. O texto que acompanha o conjunto (`TR808.TXT`, incluído aqui) chama as
amostras de "ABSOLUTELY FREE", mas **não traz uma licença formal** (nada sobre redistribuição,
uso comercial ou atribuição). Distribuídas originalmente em machines.hyperreal.org; esta cópia vem
do pacote npm `@fluid-music/tr-808`.

Arquivos usados (nomes originais → aqui): `BD2525` → `kick`, `SD5050` → `snare`,
`CH` → `hat`, `OH50` → `open`. No código do TR-808, os dígitos indicam a posição dos botões
(ex.: BD2525 = afinação 2,5 e decaimento 2,5).

## `rock/` — GMRockKit (Hydrogen)

Kit de bateria acústica (Pearl DX de 5 peças) amostrado por **Glen MacArthur / Sebastian Moors**,
distribuído com o Hydrogen sob a **GNU General Public License v3 ou posterior**
(<https://www.gnu.org/licenses/gpl-3.0.html>). Fonte:
<https://github.com/hydrogen-music/hydrogen/tree/master/data/drumkits/GMRockKit>.

Arquivos usados (nomes originais → aqui): `Kick-Hard` → `kick`, `Snare-Hard` → `snare`,
`HatClosed-Hard` → `hat`, `HatOpen-Hard` → `open`.

**Atenção:** se este projeto for distribuído com essas amostras, a GPL se aplica a elas.
